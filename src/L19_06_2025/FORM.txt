Создание формы на основе URL с GET-параметрами
Условие: Дан URL: https://example.com/search?query=apple&type=fruit&color=red&limit=10
Этот URL содержит GET-параметры:
•  query — строка поиска (например, “apple”).
•  type — тип объекта (например, “fruit”).
•  color — цвет (например, “red”).
•  limit — количество результатов (например, “10”).
Задание:
1.  Создайте HTML-форму, которая позволяет пользователю вводить значения для всех указанных GET-параметров (query, type, color, limit).
2.  Форма должна отправлять данные методом GET на адрес https://example.com/search.
3.  Поля формы должны быть следующими:
 •  query: текстовое поле для ввода строки поиска.
 •  type: выпадающий список с вариантами: “fruit”, “vegetable”, “berry”.
 •  color: выпадающий список с вариантами: “red”, “green”, “yellow”.
 •  limit: числовое поле с минимальным значением 1 и максимальным значением 50.
4.  После отправки формы URL в адресной строке браузера должен формироваться в формате, аналогичном исходному URL, с учетом введенных пользователем значений.
Пример результата: Если пользователь ввел:
•  query: “banana”
•  type: “fruit”
•  color: “yellow”
•  limit: “20”
После отправки формы URL должен выглядеть так: https://example.com/search?query=banana&type=fruit&color=yellow&limit=20
