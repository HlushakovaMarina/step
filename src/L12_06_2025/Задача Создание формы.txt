Задача: Создание формы регистрации с HTML и CSS
Цель: Создать HTML-форму регистрации пользователя с полями для ввода данных и стилизовать её с помощью CSS, чтобы она
выглядела современно и была удобной для пользователя.

Описание:
Вы — разработчик, которому поручено создать форму регистрации для сайта. Форма должна собирать данные пользователя
(имя, email, пароль, пол, интересы, страну) и отправляться на сервер. Форма должна быть не только функциональной,
но и красиво оформленной.

Требования к HTML:

Используйте тег <form> с атрибутами action="/register" и method="post".
Добавьте следующие элементы:
Поле <input type="text"> для имени (обязательное, с подсказкой "Ваше имя").
Поле <input type="email"> для email (обязательное, с подсказкой "Ваш email").
Поле <input type="password"> для пароля (обязательное, с подсказкой "Ваш пароль").
Радиокнопки (<input type="radio">) для выбора пола (мужской, женский; одна выбрана по умолчанию).
Чекбоксы (<input type="checkbox">) для выбора интересов (например, музыка, спорт, чтение; минимум 3 варианта).
Выпадающий список (<select>) для выбора страны (минимум 3 варианта, один выбран по умолчанию).
Кнопку <button type="submit"> с текстом "Зарегистрироваться".
Используйте <label> для связи с полями ввода, чтобы улучшить доступность (например, клик по метке переводит фокус на поле).
(Дополнительно) Добавьте <dialog> с сообщением "Регистрация успешна!" и кнопкой "Закрыть" (с атрибутом open для простоты).
Требования к CSS:

Подключите стили через внешний файл styles.css.
Стили для <form>:
Ширина: 400px, центрирование на странице (margin: auto).
Фон: светло-серый (#f5f5f5).
Отступы: 20px внутри формы.
Скруглённые углы: border-radius: 10px.
Стили для полей <input> (текст, email, пароль):
Полная ширина (width: 100%).
Отступы внутри: 10px.
Рамка: 1px сплошная серая.
Скруглённые углы: 5px.
При фокусе (:focus): синяя рамка и лёгкая тень (box-shadow).
Стили для радиокнопок и чекбоксов:
Отступы между вариантами: 10px.
Метки (<label>) рядом с кнопками/чекбоксами.
Стили для <select>:
Такая же ширина и рамка, как у <input>.
Отступы внутри: 10px.
Стили для <button>:
Зелёный фон (#4CAF50), белый текст.
Отступы: 10px по вертикали, 20px по горизонтали.
Скруглённые углы: 5px.
При наведении (:hover): чуть более тёмный зелёный (#45a049).
Стили для <dialog>:
Фон: белый, рамка: 1px серая.
Отступы: 20px.
Кнопка внутри: красный фон, белый текст.
Убедитесь, что текст читаем (размер шрифта: 16px для полей, 14px для меток).
Инструкции:

Создайте два файла: index.html и styles.css.
Напишите HTML-код формы, следуя требованиям.
Напишите CSS-стили, чтобы форма выглядела аккуратно.
Откройте index.html в браузере и проверьте:
Все ли поля работают (ввод текста, выбор опций).
Обязательные поля помечены (required).
Стили отображаются корректно.
(Дополнительно) Попробуйте убрать атрибут open у <dialog> и подумайте, как его можно показать с помощью JavaScript (это для обсуждения).
Подсказка:

Используйте классы для стилизации (например, .form, .input, .btn).
Для центрирования формы используйте margin: auto и width.
Тестируйте форму в DevTools (F12), чтобы проверить, как выглядят стили.
